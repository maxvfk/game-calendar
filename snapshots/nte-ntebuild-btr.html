FAQ · 4 questions

Events Calendar — FAQ

01

What events are currently live in NTE?

Beyond the Rails — Rotation (Sep 24), Foretold Finale — Blackbird Banner, Fading Reverie — Lacrimosa Rerun, Roostfeather Special — Arc Banner, Nocturne Special — Arc Banner, Terminal Depths, Circle Gifts, Pukaland Fest Special Gift Pack, Blackbird's Invitation, Pukaland Travelogue — see the full calendar below for exact end dates.

02

How often does NTE add new banners?

Each major version (roughly every 5-6 weeks) ships with two character banner phases, each running about 2-3 weeks, plus a matching arc banner and a set of limited-time events.

03

Does the events calendar include past events?

The calendar focuses on the current version onward so it stays easy to scan — older versions are archived on the patch notes page instead. Everything shown here is filterable by type (character banners, arc banners, major updates, collaborations, in-game events, livestreams).

04

Where can I see upcoming character banners?

The calendar lists confirmed upcoming banners as soon as they are officially announced, alongside a link to that character's full build guide.
